# course

Summarise and draw a recorded course — a run, a ride, a flight — from FIT, GPX, KML or KMZ,
using map data already on your own disk. Nothing about the course is sent to anybody.

Not built yet. The plan, and why the work is split between this module, `osmbase` and
`fitactivity`, is in [docs/plan.md](docs/plan.md).
